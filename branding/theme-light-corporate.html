Light Corporate

Neutral light backgrounds with a navy header. Ideal for intranet portals and corporate tooling.

The header overrides (--header-bg, --header-border) produce a dark navy bar while the rest of the page stays light.

--bg
--surface
--surface2
--accent
--ok
--warn
--crit
--oom
Header colour note: Because the header is dark navy on a light page, any logo shown via #brand-logo should be a white or light variant. Set src to a white-on-transparent SVG or PNG and add class="visible" to the <img> element in the HTML.
